# 登入學生統一學習進度

## 紀錄原則

- 只在登入學生完成一個關卡、測驗或整局遊戲時寫入。
- 訪客、教師與管理者試玩不寫入學生紀錄。
- `student_activity_attempts` 保存每次完成紀錄；`student_activity_progress` 保存各活動與模式的累積摘要。
- `attempt_key` 具有學生範圍內唯一限制，避免同一次完成事件重送後重複累加。
- 原有專用進度表（每日任務、英語單字、英語文法、元素週期表等）繼續保留；新表提供跨科統一檢視。
- 不自動上傳舊的 `localStorage` 紀錄，避免共用裝置把他人的舊進度誤歸到目前登入者。

## 部署順序

1. 先在正式 Supabase 執行 `supabase/migrations/20261017100000_add_unified_learning_progress.sql`。
2. 再發布 `SLJH-learning-hub` 前端。
3. 最後發布 `englishvocabking` 前端，使英語單字遊戲與文法練習也寫入統一摘要。

若前端先發布而資料庫尚未更新，遊戲本身仍可使用，原有專用紀錄也不受影響，但統一進度不會寫入。

## 驗收

1. 使用學生帳號完成任一整關。
2. 回到各科學習系統首頁，展開「我的遊戲與測驗進度」。
3. 確認活動、模式、完成次數、最近分數與最佳分數正確。
4. 使用管理者帳號展開「全班遊戲與測驗進度」，測試班級、學生與科目篩選。
5. 以訪客與管理者試玩同一活動，確認不新增學生紀錄。
