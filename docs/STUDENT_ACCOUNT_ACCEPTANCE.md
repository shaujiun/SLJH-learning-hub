# 學生帳號與學習進度驗收

更新日期：2026-11-22

## 驗收原則

這份驗收將「程式測試」、「正式資料稽核」及「真實裝置操作」分開記錄。程式已部署或資料表存在，不等於學生實際操作已通過。

## 已通過

### 正式資料稽核

- 有效且已核准的學生帳號共 20 個。
- 數學分組為 A 組 7 人、B 組 13 人；英語分組為 A 組 7 人、B 組 13 人。
- 數學與英語分組均無遺漏、重疊、互相衝突或無效代碼。
- 本週每日任務共 11 筆，任務分組與學生目前分組不一致為 0 筆。
- 教師或管理者紀錄混入學生統一進度為 0 筆。
- 重複作答識別碼為 0 筆。
- 作答明細與彙整進度不一致為 0 筆。
- 學生作答與彙整資料表均有「本人讀取」及「管理者讀取」政策。
- 正式統一進度已有英語聽力選字、英語情境句子、靜態舒爾特方格、因式交鋒、成語填字圖、填字圖及元素週期表等 7 種活動紀錄；各活動的明細數與摘要數全部一致。

### 程式自動化驗收

- 共同、數學 A／B 組、英語 A／B 組入口的可見性判斷正確。
- 因式交鋒：訪客預設為 B 組基礎題，學生依數學分組直接進入對應難度，且不能自行換組。
- 因式交鋒：換裝置或網址遺失每日任務編號時，會依學生帳號找回待完成任務；載入與完成時均有補登防護。
- 因式交鋒：教師與管理者只能試玩，不會寫入學生紀錄。
- 畢氏定理挑戰賽：學生依數學分組進入對應題目，每日任務可正確送出。
- 畢氏定理挑戰賽：網址遺失每日任務編號時，完成挑戰仍會找回並補登學生的待完成任務。
- 根式馬戲團、地理填圖與元素週期表：補登待完成任務後，統一學習進度會採用實際找回的任務編號，不會誤列為自由練習；舒爾特原本即符合此規則。
- 英語閱讀：訪客不可讀取、學生須通過帳號檢核、管理者可預覽、分組查詢失敗時不會默認成 B 組。
- 英語閱讀：心智圖結構化呈現、辨識文字轉題、免費提示與原文定位、A／B 組題量檢查及安全補題均有自動化測試；不會把單組限定題目誤算成另一組可用。
- 英語閱讀：手機版匯入操作改為單欄，主要按鈕至少 44 px 高；長題目、選項、回饋、狀態文字與心智圖文字均有防止水平溢出的樣式測試。
- 統一學習進度：未登入不寫入，管理者沒有學生身分時會略過，不污染學生進度。
- 全專案 115 個測試檔、610 項測試全部通過，正式建置成功。

### 已由使用者確認

- 同一學生帳號在筆電完成任務後，手機可看見完成紀錄，跨裝置同步正常。
- A 組與 B 組學生實際帳號皆可正常登入。
- 教師與學生目前的可進入區塊及操作權限正常。
- 成語填字圖在修正後重玩同一關，可完成通關與統一學習進度同步。
- 成語填字圖正式資料已有 1 筆作答明細與 1 筆進度摘要，完成數為 1，確認不是只有本機畫面成功。

## 尚待真實帳號或裝置驗收

- 以 A 組與 B 組學生逐項確認各遊戲內的題目難度與提示內容。
- 以管理者帳號實際確認全部管理功能；教師與學生權限已通過目前操作確認。
- 以管理者帳號用真實英語文章確認：心智圖儲存與重載、OCR 轉題、提示與原文定位、題量足夠／不足、安全補題逐題儲存。
- 以 A／B 組學生帳號確認英語閱讀提示、補充題判分、答錯不公布答案、答對後顯示解析與跨裝置進度。
- 在手機、平板與電腦分別完成一次任務，確認版面、送出及重新登入後的狀態。
- 對每個會計入每日任務的遊戲各測一次：完成、重玩、作答中離開、重新進入、跨裝置接續。
- 本週尚未產生正式完成紀錄的任務類型包括根式馬戲團單人對戰、地理填圖、英語口說發音，以及部分元素週期表入門任務；目前只能判定「尚未實玩」，不能判定為程式故障。

## 目前限制與風險

- 正式站目前 7 個啟用中的學習系統，`audience_scope` 都是 `common`。因此可以用自動化測試確認 A／B 組判斷，但無法在正式站驗證「A 組限定入口」與「B 組限定入口」的實際顯示差異。
- `learning_systems` 與 `learning_activities` 目前允許已登入者讀取，再由前端隱藏不符合分組的入口。未來若真的啟用 A／B 組限定入口，應再評估是否改成資料庫端直接過濾。
- 歷史科系統目前啟用，但沒有啟用中的活動。若歷史科只作為瀏覽入口，這是合理狀態；若應有每日任務或練習活動，需另行補設。
- 尚未完成平板實機驗收；在完成前不得把「手機與電腦正常」推論成「所有裝置正常」。

## 完成標準

第三優先只有在上述真實帳號與裝置項目都有結果，且失敗項目完成修正與複測後，才標記為完成。
