# 石榴國中各科學習系統

此網站位於線上聯絡簿與各科學習網站之間，負責：

- 延續同一個 Supabase 登入狀態，不再次要求學生輸入密碼。
- 只讀取學生自己的班級與分組資料。
- 依已開放的科目，每週隨機安排 1～3 次練習。
- 每天安排 1～4 項任務，每次只突出顯示一項。
- 平日未完成時，週末隨機保留約 70％；若平日全部完成，週末不新增任務。
- 英語 A 組每項 20 題、B 組每項 10 題；一般遊戲目標 80 分，口說目標 70 分。
- 自然科元素週期表分為入門、進階、挑戰與完整模式；完整模式只供自由練習，不列入每日任務。

## 專案界線

- 線上聯絡簿仍是帳號登入、學生資料與分組的來源。
- 本專案負責各科入口與專注任務排程。
- 英文單字系統負責英語遊戲、作答與回傳任務分數。
- 本專案內建自然科元素週期表遊戲，並保存學生個別等級與升級進度。
- 未來其他科目只需新增學習系統與活動資料，不必合併三個程式碼庫。

## 自然科元素週期表

- 入門：原子序 1～18，每回合 10 題；每日任務連續 3 次達 80 分後升為進階。若一直未達升級條件，最多只安排 5 個入門任務，第 6 個新任務起改為進階。
- 進階：第一週期至第六週期的第 1、2、13～18 族，再加上原子序 87、88；每回合 20 題；每日任務連續 5 次達 80 分後升為挑戰。
- 挑戰：進階內容再加入指定過渡元素、鈾與鉨；每回合 20 題，是每日任務最高等級。
- 完整：原子序 1～118，每回合 20 題，只供自由練習。
- 可練習中文名稱選元素符號、元素符號選中文名稱、週期表定位與混合挑戰。
- 只有不同的每日專注任務會累計升級次數；自由練習不計入，未達 80 分時連續次數歸零。
- 進階任務必須由該任務按鈕進入並完成；自行選擇入門自由練習不會完成進階任務。
- 管理員可在任務入口手動調整學生等級；調整後連續次數重新由 0 計算。

### 即時對戰模式

- 使用系統隨機產生的 4 位數代碼建立或加入房間，可選擇 2 人或 4 人對戰。
- 每題先有 3 秒思考時間，再開放指定學生搶答；搶到後有 5 秒作答。
- 第 1 位答對得 3 分，第 2 位答對得 2 分，後續補答者答對得 1 分；答錯或超時扣 1 分，分數可為負數。
- 4 人房採隨機分成 A、B 兩隊並計算團隊總分，起始搶答組合每 4 題循環一次。
- 空位可由 AI 補上；每位 AI 的正確率由伺服器隨機設定為 60％～80％，不顯示給學生。
- 離線座位保留 30 秒；對戰屬於自由練習，不計入每日任務或個人等級。
- 搶答、計時、作答與加扣分皆由 Supabase 原子化函式判定，前端倒數只負責顯示。

## 各科頁面共用導覽規格

每一個科目學習網站都必須提供固定浮動導覽：

- 「返回任務頁」連至 `https://shaujiun.github.io/SLJH-learning-hub/`。
- 「返回聯絡簿」連至 `https://shaujiun.github.io/SLJH114-06OCB/`。
- 電腦版放在畫面側邊並隨頁面捲動。
- 手機版改成底部橫向排列，頁面必須預留高度，不得遮住題目、答案或作答按鈕。
- 彈窗、錄音操作及主要作答按鈕的圖層必須高於或避開浮動導覽。

## 本機啟動

1. 複製 `.env.example` 為 `.env.local`，填入與聯絡簿相同的 Supabase URL 與 publishable key。
2. 執行 `npm install`。
3. 執行 `npm run dev`。

本機預設網址為 `http://127.0.0.1:4174/`。

## 資料庫

第一個 migration 位於：

`supabase/migrations/20260731090000_add_focus_learning_tasks.sql`

它只新增學習系統、學習活動、學生專注任務與作答紀錄，不修改既有聯絡簿或英文單字資料。

元素週期表遊戲與個人分級 migration 位於：

`supabase/migrations/20260806130000_add_periodic_table_science_game.sql`

因為聯絡簿與各科任務入口共用同一個 Supabase 專案，這份 migration 也必須保留在聯絡簿專案中，並以聯絡簿專案作為正式套用來源。

元素週期表即時對戰 migration 位於：

`supabase/migrations/20260806170000_add_periodic_battle_mode.sql`

它會新增對戰房間、玩家、題目、作答紀錄、即時資料表與伺服器端搶答函式；同一份 migration 也保留在聯絡簿專案，正式發布時必須先套用資料庫，再發布本網站。
