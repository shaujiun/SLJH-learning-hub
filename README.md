# 石榴國中各科學習系統

此網站位於線上聯絡簿與各科學習網站之間，負責：

- 延續同一個 Supabase 登入狀態，不再次要求學生輸入密碼。
- 只讀取學生自己的班級與分組資料。
- 依已開放的科目，每週隨機安排 1～3 次練習。
- 每天安排 1～4 項任務，每次只突出顯示一項。
- 平日未完成時，週末隨機保留約 70％；若平日全部完成，週末不新增任務。
- 英語 A 組每項 20 題、B 組每項 10 題；一般遊戲目標 80 分，口說目標 70 分。

## 專案界線

- 線上聯絡簿仍是帳號登入、學生資料與分組的來源。
- 本專案負責各科入口與專注任務排程。
- 英文單字系統負責實際遊戲、作答與回傳任務分數。
- 未來其他科目只需新增學習系統與活動資料，不必合併三個程式碼庫。

## 本機啟動

1. 複製 `.env.example` 為 `.env.local`，填入與聯絡簿相同的 Supabase URL 與 publishable key。
2. 執行 `npm install`。
3. 執行 `npm run dev`。

本機預設網址為 `http://127.0.0.1:4174/`。

## 資料庫

`supabase/migrations/20260731090000_add_focus_learning_tasks.sql`
